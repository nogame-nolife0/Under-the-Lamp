每次开灯 — 随机 hue 变色效果

拉绳开灯时 Math.random() * 360 生成新 hue，CSS 变量 --shade-hue 驱动全页面颜色联动

hue = 30° 暖金 · 默认色
hue = 340° 玫红 · 品牌色
hue = 200° 冰蓝 · 清爽
hue = 140° 薄荷绿
hue = 270° 淡紫 · 梦幻
hue = 0° 暖红 · 热烈

CSS 变量联动公式

--shade-hue: <随机 0~360>;
/* 灯泡 + 光晕 + 锥形光 */
bulb: hsl(var(--shade-hue), 85%, 60%)
glow: hsla(var(--shade-hue), 85%, 60%, 0.5)
cone: hsla(var(--shade-hue), 85%, 60%, 0.25)
/* 卡片边框 + 发光 */
card border: hsla(var(--shade-hue), 80%, 60%, 0.3)
card shadow: hsla(var(--shade-hue), 80%, 55%, 0.1)
/* 按钮 + 输入框获焦 */
button bg: hsl(var(--shade-hue), 70%, 50%)
input focus: hsla(var(--shade-hue), 70%, 55%, 0.2)
/* 台灯嘴巴 */
mouth: hsl(var(--shade-hue), 75%, 55%)
