弹性拉绳 — 任意方向拖拽

指针跟随 + 弹性伸缩 + 释放弹回，拉超过 50px 触发开关

拉绳物理模型

静止状态

拉环位于锚点正下方，绳子呈自然垂直线段。锚点固定在灯罩右侧 (145, 190)。

拉伸状态（任意方向）

拉环跟随指针移动，绳子从锚点拉伸至指针位置。超出 50px 触发阈值高亮。

各方向拉伸示意

↓ 正下方
↙ 左下
↘ 右下
↗ 右上方

交互流程

1️⃣ pointerdown

在拉环上按下时捕获指针，记录锚点坐标和初始偏移。设置 pointer-events: none 给灯罩防止误触。开始跟踪 setPointerCapture

2️⃣ pointermove

实时计算指针到锚点的距离和角度，更新拉环的 cx/cy 和绳子的 x2/y2。距离超过 50px 时拉环变色提示（触发阈值已到）

3️⃣ pointerup

距离 ≥50px → toggle 开关 + 播放咔哒声 + 随机 hue。释放后拉环 transition: all 0.5s cubic-bezier(0.34,1.56,0.64,1) 弹回锚点下方原位

实现要点

// 拉环位置：动态更新 SVG circle + line 属性
handleX = clamp(anchorX + dx, anchorX - 120, anchorX + 120)
handleY = clamp(anchorY + dy, anchorY - 80, anchorY + 120)
// 距离计算
dist = Math.hypot(handleX - anchorX, handleY - anchorY)
// 弹簧回弹 CSS
transition: cx 0.5s cubic-bezier(0.34, 1.56, 0.64, 1),
            cy 0.5s cubic-bezier(0.34, 1.56, 0.64, 1);
