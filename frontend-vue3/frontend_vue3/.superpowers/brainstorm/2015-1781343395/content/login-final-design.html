🎭 台灯关闭 vs 开启 — 状态对比

🌑 关闭 (--on: 0)
← 表单隐藏，等待开灯
💡 开启 (--on: 1)
✨ 表单弹出，灯光照亮

⚙️ CSS 变量联动机制

--on: 0 | 1

控制：灯泡发光/熄灭（opacity过渡）、眼睛旋转（transform: rotate）、表单出现/隐藏（opacity + scale）、光晕显示/隐藏、按钮渐变亮度

--shade-hue: 340~355

控制：灯泡颜色 hsl(var(--shade-hue), 85%, 60%)、光晕颜色、表单边框颜色、输入框获焦发光颜色、按钮渐变主色、所有发光 shadow 颜色

拉绳拖拽

pointerdown → pointermove（计算 dy）→ pointerup；dy ≥ 50px 触发 toggle；释放时 CSS transition cubic-bezier(0.34, 1.56, 0.64, 1) 弹回原位 + 绳子弹跳；同时播放 Web Audio 咔哒声
