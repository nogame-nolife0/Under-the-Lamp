🔍 参考图 vs 当前设计 — 关键特征对照

😊 Q版表情台灯

圆润灯罩 + 弯弯笑眼 (^‿^) + 橙红小嘴 + 粉色舌头 + 橙色腮红。使用暖金色系代替原项目的粉色系，灯光为温暖的琥珀色，符合参考图的"暖光"感觉

🔻 锥形灯光投影

从灯泡向下投射锥形暖光（polygon + linearGradient），底部桌面有光斑椭圆。灯光在深色背景上自然照亮周围区域

🪟 毛玻璃表单卡片

background 半透明 + backdrop-filter blur(24px) + 暖色微光边框。卡片颜色配合灯光色调（warm amber），关灯时卡片完全隐藏模糊

🎨 暖金配色

背景: #1a1f2e 深蓝灰。灯光: #f5c882 暖琥珀金。按钮: #e8a87c 暖杏色。所有暖色系与原项目粉色 (#e8738a) 同属暖色家族，不违和

👀 眼睛旋转 + 表情变化

开灯: 眼睛弯弯笑 (0°) + 橙嘴 + 粉舌 + 腮红。关灯: 眼睛倒转 (180°) + 表情颜色变暗，灯罩整体变灰暗

🔗 拉绳交互

右侧拉绳 + 小圆环把手。pointer 拖拽 ≥50px 触发开关。Web Audio 咔哒音效。释放时弹簧回弹动画
