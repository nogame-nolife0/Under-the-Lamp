📐 布局结构说明

Flex 横向布局

台灯 SVG (200×320px) 与登录表单 (min-width: 300px) 横向并排，gap: 48px，flex-wrap: wrap 响应式换行，小屏自动上下堆叠

CSS 变量联动

--shade-hue 控制灯光随机色相，--on: 0/--on: 1 控制开关状态，所有颜色 transitions 响应变化，表单边框和阴影同步灯光颜色

拉绳拖拽交互

拉绳 handle 可用 pointer 事件拖拽（垂直方向）。拖拽 ≥50px 触发 toggle。释放时拉绳弹回原位，绳子弹动用 CSS transition + cubic-bezier 模拟

🎨 配色轮播 — 不同 hue 值下的灯光效果

每次开灯随机 hue，表单边框和发光同步刷新

hue=350° 玫红
hue=200° 蓝
hue=140° 绿
hue=45° 暖金
